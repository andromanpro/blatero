# Локальные модели разделения говорящих

[Карта исходников и документация разработчика](README.md)

Blatero использует CPU-контур `sherpa-onnx` и не отправляет аудио наружу.
Модели устанавливаются в исключённую из Git папку `.models/`:

```powershell
.\.venv\Scripts\python.exe speaker_diarization.py install-models
```

Загрузчик принимает только закреплённые файлы и проверяет SHA-256 до установки.
Общий объём загрузки — около 47 МБ. Обработка выполняется локально на CPU;
AMD Radeon в этом контуре не используется.

| Назначение | Модель | Лицензия | Источник |
|---|---|---|---|
| Сегментация и перекрытия | `pyannote/segmentation-3.0`, ONNX int8 | MIT | `k2-fsa/sherpa-onnx` release `speaker-segmentation-models` |
| Голосовые эмбеддинги | 3D-Speaker ERes2Net base, ONNX | Apache-2.0 | `k2-fsa/sherpa-onnx` release `speaker-recongition-models` |

В поставку сами модели пока не входят: установщик должен показывать размер,
лицензию и источник до загрузки. Идентификаторы `SPEAKER_NN` — анонимные
кластеры, а не распознанные личности. Имя назначает пользователь после проверки.

## Обработка архивной записи

```powershell
.\.venv\Scripts\python.exe transcript_backfill.py sessions\<сессия> `
  --audio audio-me.wav --model small
.\.venv\Scripts\python.exe speaker_diarization.py run sessions\<сессия> `
  --audio audio-me.wav --speakers 4
.\.venv\Scripts\python.exe speaker_diarization.py merge sessions\<сессия>
```

Последняя команда также создаёт `evidence.diarized.html`. Страница нужна для
проверки количества голосов и мест смены говорящего до назначения имён. При
открытии из архива Blatero на ней можно сохранить имя, сторону и объединение;
будут созданы `speaker-map.json` и отдельный проверенный транскрипт для отчёта.
Отчёт переключится на него только после назначения имён всем необъединённым
кластерам. Если ожидаемое количество участников неизвестно, результаты
нескольких прогонов с
разными `--speakers` следует сохранять под разными именами и сравнивать по
аудио; одна только кластеризация не доказывает личность говорящего.
