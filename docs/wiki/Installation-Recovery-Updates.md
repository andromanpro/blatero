# Установка, модели, обновления и восстановление

## Переносимая Windows x64 сборка

Начиная с 0.25.0 доступен ZIP со встроенным CPython 3.12.10 и основными
зависимостями.

1. Скачайте `blatero-portable-<версия>-win-x64.zip` и `.sha256` из релиза.
2. Сверьте SHA-256.
3. Распакуйте весь архив в отдельную папку.
4. Запустите `Blatero.exe`.
5. В меню выберите **"Запустить Blatero"** или **"Открыть документацию"**.
6. Дождитесь автоматического открытия браузера.

В корне portable-папки находятся:
`Blatero.exe`, короткая инструкция, `app`, `docs`, `runtime` и `_integrity`.
Технический `app\start_blatero.cmd` остаётся запасным вариантом, если launcher
по какой-то причине не стартует.

Справка открывается в браузере без интернета и без редактора Markdown.
Запасная точка входа — `docs/wiki/Home.html`. Исходные `.md` также сохранены.
DOCX-отчёт создаётся встроенным экспортом; установка Word, Node.js или
LibreOffice для этого не требуется.

Дополнительные программы нужны только для отдельных возможностей:

- LibreOffice — для чтения старых DOC/XLS/PPT/RTF/VSD. Он не включён в архив.
  Без него можно пересохранить материалы в современные форматы на другом
  компьютере или установить LibreOffice самостоятельно.
- Codex CLI — для подключения через авторизацию ChatGPT. Он устанавливается
  отдельно по [инструкции подключения](Provider-Setup.md); ключи и авторизация
  автора программы в поставку не входят.
- Модели распознавания и голоса — по выбору пользователя через менеджер моделей.

Launcher получает фактическую папку "Документы" через Windows Known Folder и
использует её подкаталог `Blatero`. Это корректнее для перенаправленной и
OneDrive-папки. Удаление папки программы не удаляет встречи.

Portable-манифест подписан Ed25519 и покрывает каждый файл. Его можно проверить
встроенным валидатором:

```powershell
.\runtime\python.exe .\app\ci\build_windows_portable.py --verify `
  <путь-к-архиву.zip>
```

Это не публичная Authenticode/MSIX-подпись издателя. Windows может показать
SmartScreen. Сертификат издателя в текущую поставку не входит; внутренняя подпись
проверяет целостность пакета, но не отменяет предупреждения Windows.

## Установка из подписанного пакета с Python

Вариант `install_blatero.cmd` требует установленный Python 3.12 и доступ к PyPI.
Мастер проверяет внутреннюю подпись пакета, создаёт `.venv`, разделяет каталог
программы и данных и создаёт ярлык.

Для разработки можно создать окружение вручную по инструкции в README проекта.

## Запуск и access token

Launcher создаёт случайный localhost-токен в
`%LOCALAPPDATA%\blatero\access-token`, запускает сервер и открывает URL после
HTTP-проверки. Токен защищает WebSocket и локальные действия от случайной
страницы браузера. Host allowlist блокирует DNS rebinding.

После входа адрес очищается от `?token=...`; по умолчанию сервер печатает только
чистый localhost-адрес. Чувствительные страницы получают запрет кэширования,
встраивания во frame и загрузки неожиданных внешних скриптов. Не копируйте
первичный URL из адресной строки или журнала в сообщение поддержки.

Не публикуйте порт напрямую в сеть. Для LAN нужны отдельное решение по HTTPS,
явный allowlist и модель доступа пользователей.

## Менеджер локальных моделей

**Настройки → Обслуживание → Локальные модели** показывает назначение, лицензию, требования,
готовность, каталог и размер:

- Whisper base/small/medium;
- WebRTC AEC3;
- Sherpa-ONNX и модели голосов;
- Chatterbox и отдельное окружение.

Удаление разрешено только для зарегистрированных каталогов Blatero. Общий
Hugging Face cache не очищается: его могут использовать другие программы.
Удаление Chatterbox сохраняет образец вашего голоса; профиль удаляется отдельной
явной командой.

В portable runtime окружение Chatterbox создаётся через `virtualenv`, потому
что embeddable Python не содержит стандартного `venv`.

## Обновление portable

Portable обновляется только полным portable-пакетом, не ZIP исходников.

1. Остановите записи и фоновые операции, затем завершите сервер.
2. Скачайте новый portable ZIP, проверьте SHA-256 и распакуйте его в новую папку.
3. В старой установке посмотрите путь данных в **Настройки → Обслуживание →
   Обновления**. Сохраните резервную копию этой папки отдельно от программы.
4. Запустите новый `Blatero.exe`. Если раньше использовалась стандартная папка
   "Документы/Blatero", она подключится автоматически. Для нестандартного пути
   запустите из CMD с переменной только для этого окна:

   ```bat
   set "BLATERO_DATA_DIR=F:\Мои встречи\Blatero"
   "F:\Программы\Blatero-НОВАЯ-ВЕРСИЯ\Blatero.exe"
   ```

   Подставьте свои пути. Диалога выбора папки данных у portable launcher нет.
   Проверьте список встреч, настройки и открытие справки новой версии.
5. Обновите ярлык, указав новый `Blatero.exe`. Старую папку программы оставьте
   до завершения проверки. Папку данных не удаляйте.

Не копируйте `app`, `runtime` или справку поверх старой установки. Менеджер
обновлений блокирует пакет исходников в portable, чтобы версии кода, зависимостей
и справки не расходились. Ранее подготовленный несовместимый пакет отменяется
при запуске; сам ZIP сохраняется в каталоге обновлений.

Для возврата с 1.0.2-rc.7 на 1.0.1 сначала остановите новую версию и обработчик
Библиотеки, если он запущен отдельно. Дождитесь завершения сохранения заметок.
Затем запустите прежний `Blatero.exe` с той же папкой данных. Не заменяйте
данные старой резервной копией: это потеряет карточки и заметки, созданные
после обновления. Не запускайте две версии одновременно с одной папкой данных.

## Подписанные обновления установки с Python

В **Настройки → Обслуживание → Обновления** выберите пакет. До подготовки Blatero проверит:

- Ed25519-подпись;
- версию и манифест;
- размер и SHA-256 каждого файла;
- отсутствие traversal, symlink и лишних файлов.

Пакет применяется при следующем старте, когда сервер остановлен. Прежний код
сохраняется в backup. Durable transaction journal после любого прерывания
доводит состояние либо до целиком старой, либо до целиком новой версии.

Встроенный откат возвращает файлы программы, а не папку данных. Для пары
1.0.1 и 1.0.2-rc.7 новые карточки и заметки остаются доступны после возврата.
Если Библиотека сохраняет заметку или восстанавливает незавершённое сохранение,
откат откладывается до завершения операции. Не удаляйте журнал сохранения вручную.

Активная venv не меняется `pip install` по месту. Если `requirements.lock`
изменился, source-update откатывается и просит полный portable/installer, где
окружение собирается отдельно. Релиз содержит CycloneDX SBOM, строится только из
tracked-файлов и проверяется `pip-audit`.

Если нужен полный installer-пакет с другими зависимостями, установите его в
новую папку программы и выберите прежнюю папку данных. Перед этим остановите
сервер и сделайте резервную копию данных. Запустите новую установку, проверьте
встречи и настройки, затем обновите ярлык. Не удаляйте прежнюю программу до
проверки; не переносите её `.venv` поверх нового окружения.

## Восстановление после сбоя

Если питание пропало во время записи, следующий запуск показывает отдельный экран.
Для WAV и JSONL доступны:

- **восстановить и открыть** - сделать byte-identical backup и исправить только
  доказуемо оборванную последнюю часть;
- **оставить без изменений** и завершить встречу как прерванную;
- удалить только известные временные файлы.

Продолжение создаёт новый сегмент и не перезаписывает старое аудио. При нехватке
места ремонт блокируется до первой записи. Неизвестная внутренняя порча требует
ручной проверки.

## Восстановление отчёта и workspace-задачи

Фоновые задачи имеют heartbeat, generation ID, PID и cross-process lock. Старый
heartbeat живого процесса сам по себе не разрешает recovery. Целый `report.draft.md` с
совпадающим хешем источника возвращается в очередь контроля без нового LLM-
запроса. Повтор потенциально платной операции без контрольной точки всегда
требует отдельного подтверждения.

Старый background job не может опубликовать результат после переключения на
другую сессию.

## Миграция схемы сессии

Legacy-сессия обновляется лениво при открытии: журнал, backup `meta.json`, новый
файл и commit-marker публикуются в проверяемом порядке. Прерванная миграция
повторяется идемпотентно. Сессия из более новой версии Blatero блокируется без
изменения файлов.
