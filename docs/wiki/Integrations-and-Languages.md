# Интеграции и язык интерфейса

Сверено 1 ноября 2026 года. Blatero можно использовать без соседних приложений.

## Включить или отключить подключение

1. Во встрече откройте **Настройки → Интеграции**. На отдельной доске —
   **Настройки** в верхней панели.
2. Выберите Neon Legion или Гранку и нажмите **Сохранить**.
3. В разделе **Материалы** обновите источники. Для Neon откройте
   **Эффективность**. Включение не означает, что приложение уже найдено и доступно.

Подключения по умолчанию выключены. Настройка общая для локальной базы проектов,
а не для одной встречи. Менять её может локальный пользователь, не агент.

Отключённое подключение не запускает экспортёр и не читает журналы соседней
программы. Старые снимки и связи сохраняются; новые карточки из отключённого
источника не создаются. Даты отключённой Гранки не добавляются в план.
Оригиналы статей и журналов Blatero не изменяет.

### Neon Legion

Связывает локальные журналы использования ИИ с задачами по точным сессиям и
времени привязки. Показывает эквивалент API, не стоимость вашей подписки и не
измерение человеческого рабочего времени. Неполное покрытие не означает нулевые
расходы. Адаптер читает JSONL, а не импортирует код Neon.

По умолчанию ожидается соседняя папка `neon-legion`. Другой путь можно задать
переменной окружения `BLATERO_NEON_ROOT` до запуска Blatero.

### Гранка

Локальный редактор статей с замечаниями ИИ, версиями и публикацией. Blatero
читает экспорт каталога и связывает статьи с карточками. Редактирование остаётся
в Гранке. Это не автоматическая отправка отчётов в канал и не изменение статей.

По умолчанию ожидается соседняя папка `granka` с экспортёром
`tools/blatero_export.py`. Для другого места: `BLATERO_GRANKA_ROOT`.
Для отдельного Python экспортёра: `BLATERO_GRANKA_PYTHON`. Сам экспортёр
запускается локально только при включённом подключении.

### Мотивелиум

Упомянут в **Помощь → Другие приложения** как отдельный инструмент для работы
с роликами. Прямого обмена с Blatero пока нет, поэтому переключателя подключения
нет. Устанавливать его для встреч не требуется.

## Русский и English

Во встрече: **Настройки → Внешний вид → Язык интерфейса**. На отдельной доске:
**Настройки → Язык интерфейса**. Выбор сохраняется в текущем браузере, действует
на обе страницы и применяется без перезапуска сервера.

RU/EN доступны для навигации, настроек, подготовки и записи встречи, отчёта,
трекера, студии, библиотеки, лабораторий и обслуживания. Техническая ошибка
Windows или провайдера может остаться на исходном языке. Ключи, имена, названия
моделей, пути и содержимое документов не переводятся как интерфейс.

Язык интерфейса не меняет язык распознавания и запросов ИИ. Текст встреч,
названия проектов, имена, пути и отчёты автоматически не переводятся. Переключение
не даёт согласия на облачную обработку и не меняет ключи или голосовые настройки.

Живые профили Whisper и SpeechKit в этой версии настроены на русский язык.
Локальный детектор имён также ориентирован на русский текст. Английский
интерфейс не означает автоматическую поддержку англоязычного звонка.
