# Подключение провайдеров

Эта страница нужна для первого запуска portable-сборки. Blatero может работать
полностью локально, но подсказки, отчёты, SpeechKit и облачные голоса требуют
отдельной настройки провайдера.

Сверено 1 ноября 2026 года по коду Blatero и официальным инструкциям. Интерфейсы провайдеров меняются, поэтому рядом
оставлены ссылки на официальные инструкции.

## Что выбрать для тестирования

| Задача | Рекомендуемый вариант | Что понадобится |
|---|---|---|
| Быстро проверить подсказки и отчёт | OpenRouter | аккаунт OpenRouter, баланс, API key |
| Использовать подписку ChatGPT без OpenRouter | Codex / подписка ChatGPT | установленный Codex CLI и вход в ChatGPT |
| Прямо платить OpenAI API | OpenAI | API key OpenAI Platform |
| Распознавать речь через Яндекс | Yandex SpeechKit | Yandex Cloud, service account, API key |
| Озвучивать вопросы голосами Яндекса | Yandex TTS | тот же Yandex Cloud доступ с ролью TTS |
| Работать без облака | Whisper + локальная LLM | локальные модели и ресурсы компьютера |

Для первого теста коллеги проще всего:

1. оставить STT как **локальный Whisper**;
2. выбрать LLM **OpenRouter** или **Codex / подписка ChatGPT**;
3. включить **"Согласие получено - облачные функции разрешены"** только если
   действительно будете отправлять текст внешней модели;
4. нажать **"Проверить соединение"**.

## Где вводить настройки в Blatero

Откройте **Настройки → ИИ и подсказки**.

1. Выберите LLM-провайдера.
2. Вставьте API-токен, если выбран прямой API-провайдер.
3. Для OpenAI-compatible endpoint укажите Base URL и модель.
4. Нажмите **"Сохранить"**.
5. Нажмите **"Проверить соединение"**.

Проверка соединения не отправляет транскрипт, резюме или рабочую папку. Она
использует минимальный технический запрос.

API-токены сохраняются в Windows Credential Manager / системном keyring и не
возвращаются браузеру. Не передавайте `config.json` как способ переноса ключей:
секретов в нём быть не должно.

## OpenRouter

OpenRouter удобен как единый ключ к разным моделям.

Что сделать:

1. Откройте [OpenRouter API keys](https://openrouter.ai/settings/keys).
2. Войдите или создайте аккаунт.
3. Создайте API key, задайте понятное имя, например `Blatero test`.
4. При желании задайте лимит расходов на ключ.
5. Скопируйте ключ один раз и вставьте его в Blatero.
6. В Blatero выберите модели для быстрых подсказок и глубокого отчёта.
7. Нажмите **"Проверить соединение"**.

Официальная справка: [OpenRouter authentication](https://openrouter.ai/docs/api_reference/authentication).
OpenRouter использует Bearer API key и совместимый endpoint
`https://openrouter.ai/api/v1`.

Если проверка пишет 402 или не хватает лимита, проверьте баланс OpenRouter и
лимит конкретного ключа.

## Codex / подписка ChatGPT

Этот маршрут нужен, если вы хотите использовать подписку ChatGPT вместо
OpenRouter API key. В Blatero при выборе Codex поле API-токена скрывается.

Что сделать:

1. Установите Codex CLI по официальной инструкции:
   [Codex CLI](https://developers.openai.com/codex/cli).
2. Откройте обычный терминал Windows.
3. Выполните:

```powershell
codex login
```

4. Выберите вход через ChatGPT и завершите авторизацию в браузере.
5. Вернитесь в Blatero.
6. В **Настройки → ИИ и подсказки** выберите
   **Codex / подписка ChatGPT**.
7. Нажмите **"Проверить соединение"**.

Официальная справка OpenAI: [Codex authentication](https://learn.chatgpt.com/docs/auth#codex-cli)
и [Using Codex with your ChatGPT plan](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan).

Важно:

- Codex в Blatero запускается без агентных инструментов.
- Транскрипт, резюме и рабочая папка передаются как данные для модели, а не как
  команды на чтение файлов или запуск действий.
- Лимиты зависят от вашего плана ChatGPT.
- Если нужно платить строго за API-токены, выбирайте OpenAI API или OpenRouter,
  а не Codex-подписку.

## OpenAI API напрямую

Этот маршрут использует API-ключ OpenAI Platform, а не авторизацию Codex.
Доступные лимиты и биллинг проверьте в своём API-проекте.

Что сделать:

1. Откройте [OpenAI Platform API keys](https://platform.openai.com/api-keys).
2. Создайте project API key.
3. Скопируйте ключ и вставьте его в Blatero.
4. Выберите модели для подсказок и отчёта.
5. Нажмите **"Проверить соединение"**.

Если в аккаунте нет биллинга или лимитов, проверка может пройти с ошибкой
доступа или квоты.

## Yandex SpeechKit STT

Yandex SpeechKit нужен только если вы выбираете облачное распознавание речи или
облачные голоса Яндекса. Для обычного локального теста можно оставить Whisper.

Что сделать в Yandex Cloud:

1. Создайте или выберите каталог Yandex Cloud.
2. Создайте service account для Blatero.
3. Назначьте ему роль для SpeechKit STT, например `ai.speechkit-stt.user`, на
   нужный каталог.
4. Создайте API key для service account. Для распознавания разрешите scope
   `yc.ai.speechkitStt.execute`; для озвучки дополнительно нужен
   `yc.ai.speechkitTts.execute`. Scope ключа не заменяет роль аккаунта.
5. Сохраните секретную часть ключа одной строкой в файл
   `%USERPROFILE%\.yc-speechkit-key` без добавления `.txt`. В текущем интерфейсе
   нет поля ввода этого ключа: он читается локальным SpeechKit-модулем.
6. В **Настройки → Звук и речь** выберите **Yandex SpeechKit** и сохраните.
7. Включите **"Согласие получено - облачные функции разрешены"**.
8. Нажмите **"Проверить всё"** или проверку STT.

Официальная справка:

- [SpeechKit authentication](https://yandex.cloud/en/docs/speechkit/concepts/auth)
- [Yandex Cloud API key](https://yandex.cloud/en/docs/iam/concepts/authorization/api-key)
- [Streaming recognition API v3](https://yandex.cloud/en/docs/speechkit/stt/api/streaming-examples-v3)

Этот адаптер использует заголовок `Api-Key`: IAM token и JSON авторизованного
ключа нельзя подставлять в этот файл. Файл содержит секрет в открытом виде,
не переносится в Windows Credential Manager и не должен попадать в Git,
архив поставки или диагностику. Ограничьте доступ к нему своим пользователем
Windows; при утечке отзовите ключ в Yandex Cloud и создайте новый.

Если SpeechKit не работает, проверьте:

- роль service account;
- что ключ создан именно для нужного service account;
- что облачная галочка включена;
- что выбран SpeechKit, а не локальный Whisper;
- баланс и лимиты Yandex Cloud.

## Yandex TTS

Yandex TTS используется для озвучивания вопросов и SIM, если выбран маршрут
**"мой голос -> Яндекс"** или **"только Яндекс"**.

Что сделать:

1. Используйте тот же Yandex Cloud каталог и service account.
2. Назначьте роль для SpeechKit TTS, например `ai.speechkit-tts.user`.
3. Проверьте, что в Blatero выбран нужный голос.
4. Включите облачную галочку.
5. Нажмите проверку голоса.

Официальный пример: [Speech synthesis API v3](https://yandex.cloud/en/docs/speechkit/tts/api/tts-examples-v3).

Если слышны бессмысленные слоги или шум, это не проблема ключа. Проверьте
локальный Chatterbox, выбранный голос, fallback и аудиоустройство вывода.

## OpenAI-compatible локально

Для локальных серверов вроде Ollama, LM Studio или vLLM:

1. Запустите локальный сервер.
2. Укажите Base URL, например `http://127.0.0.1:11434/v1`.
3. Укажите имя модели.
4. Токен оставьте пустым, если локальный сервер его не требует.
5. Нажмите **"Проверить соединение"**.

HTTP разрешён только для loopback-адресов `127.0.0.1`, `::1` и `localhost`.
Внешний endpoint должен быть HTTPS и считается облачным маршрутом.

## Что отдавать коллеге вместе с portable

Минимальный комплект:

- `blatero-portable-<версия>-win-x64.zip`;
- файл `.sha256`;
- короткая инструкция `PORTABLE_README.txt` внутри архива;
- автономная справка в `docs/wiki/Home.html` и `docs/wiki/en/Home.html`;
- отдельное сообщение: какой LLM-провайдер использовать и кто оплачивает ключи.

Не передавайте свои API-ключи, Yandex key, OpenRouter key, Codex login, папку
`sessions`, `config.json`, `.voice-profile` и экспортированные реальные встречи
без отдельного решения.

## Быстрая диагностика

| Симптом | Что проверить |
|---|---|
| LLM не подключается | выбран провайдер, сохранён токен, нажата проверка, есть баланс |
| Codex не виден | установлен Codex CLI и выполнен `codex login` тем же пользователем Windows |
| SpeechKit заблокирован | включена облачная галочка и выбран Yandex SpeechKit |
| Проверка не отправляет текст | это нормально: она не должна отправлять материалы встречи |
| Работает локально, но не у коллеги | токены не переносятся в ZIP; их нужно настроить на его машине |
