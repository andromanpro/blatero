# Pilot testing

The pilot checks whether a colleague can launch, prepare, record, read and create
a useful report. It is not proof of universal device or accessibility support.
Use synthetic test data and your own credentials first.

## A first independent test

1. Extract all portable files, start Blatero.exe and open offline Help.
2. Select test data and create a short topic-only meeting.
3. Configure local Whisper and optional AI access, then save.
4. Run Check all with its readiness/countdown instruction.
5. Record 1–3 minutes only when you intend capture, stop and verify the source.
6. Review unknown participants if needed, generate/review DOCX and find its folder.
7. Confirm a synthetic agreement and prepare a new related test meeting.
8. Calculate/review deletion of the test data or export it deliberately.

Record where you hesitated, labels that overflowed, misunderstood permissions,
unclear model/elapsed states, missing beginning/end of speech, incorrect voices
or unsupported report conclusions. Report whether test/work separation, timestamps
off by default and deletion were understandable without an assistant.

## Boundaries

Automated synthetic checks on the release machine do not prove a clean foreign
Windows 10/11, Bluetooth, antivirus/CFA, all browser/device combinations or full
screen-reader coverage. Limited earlier Firefox/NVDA testing is not a complete
test of this exact package. Multi-person speaker quality and Audio Guard threshold
calibration require a varied confirmed real corpus, typically 10–20 recordings.

These are recorded support limits, not a reason to claim a fresh physical call
happened when it did not. If the basic route loses audio, mixes test/work or
requires an expert to find every action, fix that route before expanding the pilot.

Share only sanitized diagnostics and a concrete sequence. Do not send a colleague
the author's keys, real sessions, private project board or internal legal/product
notes. [Installation](Installation-Recovery-Updates.md), [Rules](Recording-and-Policy.md).
