# Workspace quickstart

The shared navigation is **Today, Meetings, Projects, Plan, Materials, Library,
Archive**. All use the same server/address. A standalone board process is optional
and does not replace the meeting server. **Help** works from either page; on
narrow screens its button is a question mark.

## Track a task without a meeting

1. Open Projects, choose/create a project and optionally set its local folder.
2. Create a card with a concrete expected result.
3. Fill goal, method, rationale and next step; save.
4. Move it to Active. Add evidence/checks as work changes.
5. Send the result to Review. Done requires separate acceptance by the owner or
   an authorized reviewer; ending an agent session is not acceptance.

Use dragging or a keyboard-operable status menu. **Show more** loads up to 40
additional cards in one column without resetting other columns. Historical
imports are labelled provisional. Close an obsolete card with a reason; it remains
under Closed and can be restored explicitly, not silently edited as active work.

## Connect a meeting

In a meeting open **Meeting tasks**, check the project and create/link a card.
A project suggestion based on folder/name is not itself a link. The source
snapshot and return link stay in the card. Refreshing a source does not accept
the task or replace its method. Active recording restricts session changes.
Use [new project/task meetings](Meetings-and-Preparation.md) for quick preparation.

## Plan the week

Plan combines meetings, task intervals/deadlines and optional article dates.
Set start and estimated duration in a card. Computer-local input and the Moscow
weekly display are labelled; overlaps are flagged. A linked meeting and task
with the same interval do not occupy two slots. Materials can create/link a card
from a meeting, agreement or article. Calendar sources are last local snapshots.
Granka is read-only here: changing a task does not publish or reschedule an article.

## Recall a decision

Open Recall in the project/card, explain goal/method/reason **before** revealing
the card, then compare. Self-ratings schedule return in 1/3/7 days. Your retelling
is not saved or model-graded; there are no automatic reminders. A content change
can make the old basis stale. This is optional recall, not interview evaluation.

## Today, library and agents

[Today](Daily-Workspace.md) has one owner-selected focus, explicit questions,
results awaiting review, the next seven days and up to two recall topics.
[Library](Knowledge-Library.md) searches selected documents, decisions and source
history. Freshness, proposal state and user confirmation are distinct.

Agents bind a session to a task, record decisions/evidence and save a per-turn
receipt. Hooks do not invent rationale or accept work. Conflicting revisions
require rereading context. [Projects and the protocol](Projects.md).

Efficiency optionally reads Neon Legion. API-equivalent usage is not your
subscription invoice or measured human work/time saved. Missing coverage/price
does not mean zero cost. No integration is required to use the board.

## Preferences and opening

Theme, motion, language and layout are browser preferences in Settings. Reduced
motion from the OS has priority. Closing the startup guide does not clear its
show-on-startup checkbox. The board opens the guide manually.

When the server is running, open its normal local address. Local browser auto-
login is an explicit option, not guaranteed in every installation. If requested,
use the launcher to establish a browser session; do not share the token-bearing
initial URL. A web link alone cannot start a stopped local server.
